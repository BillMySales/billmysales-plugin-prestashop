Plugin BillMySales para PrestaShop
===============================

Este plugin permite integrar PrestaShop con la
[Aplicación Web de BillMySales](https://billmysales.cl).

Funcionalidades implementadas:

- Emisión de Boleta desde un pedido pagado de PrestaShop.

![Configuración del Plugin en PrestaShop](https://imgur.com/a/6xQ930U "Configuración del Plugin en PrestaShop")

El plugin fue probado con PrestaShop 1.7.8.2

Para que este plugin pueda ser usado se requiere una cuenta activa en [BillMySales](https://billmysales.com).

Instalación
-----------
- Descargar o clonar el repositorio, este descargara una archivo ZIP llamado "billmysales-plugin-prestashop.zip".
- Se debe renombrar descomprimir el archivo y renombrar la carpeta a "billmysales".
- Comprimir la carpeta renombrada.
- Subir el plugin a PrestaShop.
